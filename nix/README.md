# NixOS module

The flake exposes a NixOS module, `nixosModules.default`, that builds the portfolio and serves it with nginx. It builds the site **once per domain**, so each domain gets its own canonical URL (`<link rel="canonical">`, `og:url` and JSON-LD).

## Quick start

Add the flake as an input and import the module:

```nix
# flake.nix of your NixOS configuration
{
  inputs.portefolio.url = "github:EniumRaphael/portefolio";

  outputs = { nixpkgs, portefolio, ... }: {
    nixosConfigurations.myhost = nixpkgs.lib.nixosSystem {
      system = "x86_64-linux";
      modules = [
        portefolio.nixosModules.default
        ./configuration.nix
      ];
    };
  };
}
```

Then enable the service:

```nix
# configuration.nix
{
  services.portefolio = {
    enable = true;
    domains = [ "example.net" "example.com" ];
  };

  # Required by enableACME (the default), see "TLS" below
  security.acme = {
    acceptTerms = true;
    defaults.email = "you@example.com";
  };

  networking.firewall.allowedTCPPorts = [ 80 443 ];
}
```

## Options

All options live under `services.portefolio`.

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `enable` | bool | `false` | Serve the portfolio as a static site with nginx. |
| `domains` | list of str | none (required) | Domain names to serve. Each one has its own build and canonical URL. Must not be empty. |
| `cv` | attrs | `import ./cv.nix` | CV data ([JSON Resume](https://jsonresume.org/schema/) schema). Replaces `cv.json`. |
| `user` | str | `"portefolio"` | User the nginx workers run as. |
| `group` | str | `"portefolio"` | Group of `user`. |
| `createUser` | bool | `true` | Create the system user and group. Disable it if they already exist. |
| `forceSSL` | bool | `true` | Redirect HTTP to HTTPS. |
| `enableACME` | bool | `true` | Automatic Let's Encrypt certificate for each domain. |

## How it works

- For each entry of `domains`, the module calls the package with `siteUrl = "https://<domain>"` and uses the result as the `root` of an nginx virtual host. `siteUrl` is passed to the Astro build as `SITE_URL`.
- The `cv` attrset is serialized to `cv.json` at build time, so the site content comes from Nix and nothing has to be generated by hand.
- Each virtual host uses `try_files $uri $uri/index.html =404`.
- The module enables `services.nginx` and sets its `user` and `group` with `lib.mkDefault`, so you can override them.

## Customize the CV

The default content is `nix/cv.nix`. Override it from your configuration:

```nix
{
  services.portefolio.cv = import ./my-cv.nix;
  # or tweak the default one:
  # services.portefolio.cv = (import "${inputs.portefolio}/nix/cv.nix") // {
  #   basics = { ... };
  # };
}
```

The theme is selected with `basics.theme` (`default`, `blue`, `cyber`, `green`, `red`, `mocha`, `tokyonight`).

## TLS

With `enableACME = true` (the default), NixOS requests a certificate for each domain through the HTTP-01 challenge. You must:

- accept the ACME terms and set a contact email (`security.acme.acceptTerms`, `security.acme.defaults.email`),
- point the DNS records of every domain to the host,
- open ports 80 and 443 (the module does not touch the firewall).

To serve plain HTTP (for example behind a reverse proxy that terminates TLS), disable both:

```nix
services.portefolio = {
  enableACME = false;
  forceSSL = false;
};
```

## nginx user

`user` and `group` apply to the nginx workers. nginx is shared, so this also affects every other virtual host of the machine. If that is a problem, keep your own user with `createUser = false` and set `user` / `group` to it, or override `services.nginx.user` yourself.

## Without the module

The flake also provides a ready-to-use package for `x86_64-linux` and `aarch64-linux`, built for `https://example.com`:

```bash
nix build   # the static site is in ./result
```

To build for another URL, call `nix/package.nix` with your own `cv` and `siteUrl`.

## Maintenance

When the pnpm dependencies change (`pnpm-lock.yaml`), the fixed-output hash in `nix/package.nix` (`pnpmDeps.hash`) must be updated: set it to `lib.fakeHash`, run `nix build`, and copy the hash from the error message.

The module uses the `pkgs` of your own system, so your nixpkgs must provide `fetchPnpmDeps` and `pnpmConfigHook`.
